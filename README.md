<h1 align="center">Kyreqo</h1>

<p align="center">
  Kyreqo is a modern web-based API testing platform built with React and Django REST Framework.
</p>

## Features

- REST API Testing
- Request Collections
- Workspaces
- Request History
- Environment Variables
- JWT Authentication

## Tech Stack

### Frontend
- React (Vite)
- TypeScript
- Tailwind CSS

### Backend
- Django
- Django REST Framework
- PostgreSQL

🚧 Currently under development.
