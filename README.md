# Kyreqo

Kyreqo is a modern web-based API testing platform built with React and Django REST Framework.

## Features

- REST API Testing
- Request Collections
- Workspaces
- Request History
- Environment Variables
- JWT Authentication

## Tech Stack

### Frontend
- React (Vite)
- TypeScript
- Tailwind CSS

### Backend
- Django
- Django REST Framework
- PostgreSQL
