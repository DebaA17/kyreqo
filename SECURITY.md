# Security Policy

## Supported Versions

The active development of Kyreqo takes place on the `main` branch, which is the only supported version for security updates.

## Reporting a Vulnerability

If you find a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, report it securely using **GitHub Private Vulnerability Reporting**:

1. Navigate to the **Security** tab of this repository.
2. Select **Vulnerability advisories**.
3. Click **New draft security advisory** to report the issue privately.

## Resolution Timeline

We aim to address and resolve any valid security reports within **5 to 7 days** from the date of submission.
